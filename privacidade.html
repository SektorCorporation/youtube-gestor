Política de Privacidade

Esta política explica como o YouTube Gestor trata os dados acessados pelas APIs do YouTube.

Dados acessados

Com a autorização do usuário, o YouTube Gestor acessa: as informações dos canais autorizados (nome, identificador, contagem de inscritos e vídeos), os vídeos desses canais e seus dados (título, descrição, tags, miniatura, status), e as métricas do YouTube Analytics desses canais.

Uso dos dados

Os dados são usados apenas para o próprio usuário enviar e editar vídeos nos seus canais e acompanhar as métricas deles. Nenhum dado é usado para publicidade, vendido ou repassado a terceiros.

Armazenamento

Os dados e as chaves de acesso (tokens OAuth) ficam guardados somente no computador do usuário, em pastas com acesso restrito ao próprio usuário. O YouTube Gestor não tem servidor e não envia esses dados para nenhum lugar além das APIs do Google.

Revogação e exclusão

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions. Ao revogar ou ao apagar os arquivos locais do YouTube Gestor, todos os dados guardados deixam de existir. Dados de métricas guardados localmente são atualizados ou apagados em no máximo 30 dias.

Serviços do Google

O YouTube Gestor usa os Serviços de API do YouTube. Ao usá-lo, o usuário concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
